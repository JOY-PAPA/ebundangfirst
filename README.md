# e편한세상 분당 퍼스트빌리지 옵션 계산기

새로 업로드한 엑셀 파일의 `옵션DB` 시트를 기준으로 만든 정적 웹 계산기입니다.

## 구성

- `index.html`: 화면 구조
- `styles.css`: 반응형 화면 스타일
- `app.js`: 선택, 합계, 필터, 공유, CSV, 인쇄 로직
- `analytics.js`: GoatCounter 방문 통계 연결
- `option-data.js`: 엑셀 `옵션DB`에서 추출한 옵션 데이터
- `assets/bg_visual_pc.png`: 헤더 배경 디자인 이미지
- `.nojekyll`: GitHub Pages 정적 배포용 파일

## 로컬 확인

```bash
py -m http.server 8100
```

브라우저에서 아래 주소를 엽니다.

```text
http://localhost:8100
```

## 데이터 수정

엑셀 `옵션DB` 시트의 열 구조는 아래 순서를 기준으로 합니다.

```text
ID, 구분, 품목, 구성/조건, 제조사, 택1그룹, 51A, 55A, 55B, 59A, 59T, 비고
```

가격 빈칸은 웹에서 `해당 없음`으로 표시되며 선택할 수 없습니다.

## 주의

### 방문 통계

2026-09-29부터 GoatCounter 계정 `chosh`로 방문 통계를 집계하도록 설정했습니다. [통계 대시보드](https://chosh.goatcounter.com/)에 계정 소유자로 로그인하여 기간별 방문 수를 확인합니다.

`index.html`의 `data-goatcounter-site="chosh"`가 연결 계정을 지정합니다. 이 값을 비우고 다시 배포하면 통계 수집이 중단됩니다. 비밀번호나 API 키는 사이트 코드에 저장하지 않습니다.

공식 배포 주소 `https://joy-papa.github.io/ebundangfirst/`의 페이지 방문만 집계합니다. 공유 링크의 주택형·선택 옵션, 검색어, 계산 금액, 유입 주소는 전송하지 않습니다. 로컬 파일과 미리보기 서버는 집계하지 않습니다. 통계 스크립트는 비동기로 로드되며, 차단되어도 계산기는 계속 작동합니다.

통계는 연결 완료 시점부터 쌓입니다. 방문 수는 사람의 정확한 실인원과 다를 수 있으며, 광고 차단기를 사용한 방문은 누락될 수 있습니다. [설치 안내](https://www.goatcounter.com/help/start) · [통계 설정](https://www.goatcounter.com/help/js)

### 계산기 안내

본 계산기는 입주예정자 편의용 참고 계산기입니다. 실제 계약 전에는 공식 공고문, 계약서, 견본주택 안내를 최종 기준으로 확인해야 합니다.
